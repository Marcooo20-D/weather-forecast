  format lama, immutable issue, pembacaan bertahap, staging aman, file wajib,

- Rebuild tiga lokasi dari data repo berhasil; **216 nilai peluang hujan dan
  tanggalnya** cocok dengan sembilan berkas Sentinel sumber.
- Paket dari snapshot lengkap yang relevan: **128 file, 3.540.993 byte**,
  dibanding 6.085 file/5.935.916.645 byte pada publikasi lama. Ukuran paket
  berikutnya dapat berubah sesuai data. Angka ini membandingkan isi file,
  bukan ukuran transfer Git yang sudah dikompresi.
- Satu snapshot ensemble nyata berukuran 12.546.402 byte menjadi 248.170 byte
  dengan gzip. Arsip baru memakai serialisasi ringkas dan gzip tanpa mengurangi
  informasi; data keluaran tes dipastikan dapat dibaca kembali.
- `compileall`, pemeriksaan YAML lokal, dan `git diff --check` lulus.

## Penerapan dan batas

Perubahan disiapkan untuk review. Setelah PR kode digabung ke `main`, pemicu
push menjalankan forecast baru dan menerbitkan paket ke `gh-pages` secara
otomatis. Ini mencegah perbaikan langsung pada `gh-pages` ditimpa lagi oleh
generator lama pada run berikutnya.

Belum ada klaim waktu deploy baru karena pipeline produksi belum dijalankan
dengan perubahan ini. Perbandingan ukuran bukan jaminan durasi tertentu.
Panggilan penuh ke seluruh provider cuaca tidak diulang dari lingkungan audit;
pengujian memakai data repo dan fixture offline. Prakiraan baru akan diperoleh
workflow setelah merge.

Pemeriksaan visual browser tidak dapat diselesaikan: binary Chromium tidak
tersedia dan unduhannya tidak menghasilkan ZIP yang valid di lingkungan ini.
Sintaks JavaScript dan integritas hasil build telah diperiksa, tetapi interaksi
peta dengan CDN/tile eksternal masih perlu diamati pada run produksi.

Arsip lama `main` dan riwayat Git tidak ditulis ulang atau dihapus. Checkout
produksi masih membawa arsip lama; perbaikan ini memangkas publikasi serta
pertumbuhan arsip baru. Perombakan satu file mesin yang berisi banyak override
versi lama ditunda agar perbaikan terukur ini tidak sekaligus mengganti semua
perhitungan. Direktori `trading-dashboard/` adalah aplikasi terpisah: sintaks
dan konfigurasi statis diperiksa, tetapi strategi, hasil trading, dan koneksi
pasarnya tidak diubah.

Semua lokasi masih memerlukan observasi lokal yang cocok untuk pembuktian
akurasi; menambah tampilan atau model tidak otomatis membuktikan kalibrasi.
